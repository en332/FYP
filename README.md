# FYP

# This is a repository for all code used in FYP project:

# Preprocessing script: all preprocessing steps, from HALo extraction to exporting clean datasets

# Functions: all functions necessary for calculations in later scripts

# Plotting: all code for graph plotting

# Characteristic_stats: statistical testing for characterisation data (area, count, density, and ins/gcg per tissue section)

# Inflammation_stats: statistical testing for inflammation data (CD45 staining per EO, and per whole parenchyma)

# PCA: Script for running PCA (principal component analysis)
